# AGENTS.md

`ikigai-dotnet` is the ikigai wire protocol for .NET (a client and a servable peer); see `PLAN.md` for what is built
and what is planned.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages, pages, terminal text.
- Keep the vector files under `tests/vectors/` verbatim, with LF line endings; CI checks their digests.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-dotnet/security/advisories/new), never a
  public issue.
- Write American spelling (behavior, color, labeled).
